一、集市三层结构定版（2026-09-11 主人契约：集市三分）

集市三分：客集 X-Customer（谁在买）/ 集市 X-Market（在哪成交）/ 供集 X-Supply（谁在卖）。三层=「我要干什么」的结构分层，与登入端六容器（「我是谁」）分轨，不得混放——容器卡归 /entrance，三层导航归集市域内页面。

层系统代码一句话定位Market 落地
客集X-Customer谁在买——客户进店选货，需求从这里进来X-Mall（C-Market）客户端 / Market 客户工作台
集市X-Market在哪成交——询价报价签约下单，交易在这里完成X-Goods（E-Market）等集市 Plat / B2B 成交链路
供集X-Supply谁在卖——供给方摆货上架，货源从这里进来X-Supply 供给四源集市（供给方/经营方进入）

二、资源集别名表（322 全景图 v3 终版）

别名挂接：一客集挂 CRM；四供集挂 SCM / TAMS / HRM / FAMS。集市层（X-Market）无资源集别名——别名属于资源面（客/供），不属于成交面。

别名资源集挂接层域域说明
CRM客户资源客集 X-Customer客域 C客户/流量/需求线索（授权式/贡献式，不占权位）
SCM供应链供集 X-Supply供域 E物资与产能供给（EU 源头产能）
TAMS技术资产供集 X-Supply技域 T技术供给（TU 源头产能）
HRM人力资源供集 X-Supply人域 H人力供给（HU 源头产能）
FAMS场地资产供集 X-Supply场域 Y空间与场地供给（YU 源头产能）

三、Plat 族定名（322 全景图 v3 终版别名）

集市域内六大 Plat，模块≠客户端——Plat 是集市面模块实例（{Plat} = {域}-Market），客户端是登录入口（/entrance 六容器）。

Plat市场别名域中文定名Market 落地
X-MallC-Market客域 C商城已上线（Mall 零售货架，买家 CU）
X-GoodsE-Market供域 E通货集市占位页（XMK-STRUCT-01，真 UI 后续单）
X-TechT-Market技域 T技术集市预留（真 UI 后续单）
X-CajobH-Market人域 H人事集市预留（真 UI 后续单）
X-JezoomY-Market场域 Y空间集市预留（真 UI 后续单）
X-OFD履约中心 Plat跨域履约中心只读接入（模拟契约期，Govern/供给治理台挂载）
消歧红线：Booth-C（客域供给实体铺，历史概念）≠ Booth-CDP（零售店，Booth 六形态正式编码）；模块≠客户端（X-Goods 是集市面 Plat，不是客户端）；界面文案零帽名（中文名走 terminology v1.4 常量：MARKET_LAYERS / RESOURCE_SET_TERMS / PLAT_TERMS）。
