# XMK-MALL-RICH-01 集市内容扩容单（大单制：连续执行到交付，一次回报）

## 背景
主人巡视线上：消费者（客户）在 /mall（X-Mall=C-Market 消费集市）内容太少——商品少、页面空，没有"逛集市"的感觉。要求增加内容。

## 目标（一次做完整）

### 1. 商品数据扩容（真实落库，禁 mock 接口）
- 真实落库 ≥30 SKU，多品类分布：食品生鲜 / 粮油调味 / 地方特产（贴合知味生态调性）/ 日用百货
- 每商品：名称、分类、价格、库存、描述、图片位齐全
- 图片：用本地生成资产（SVG/渐变占位卡或 data URI），严禁外链不可达图
- 商品数据与现有商品/供集模型对齐（先盘点现有 schema，扩数据不破模型）

### 2. /mall 集市页升级（逛购体验）
- 商品网格（卡片：图/名/价/分类标）
- 分类筛选 + 关键词搜索 + 价格排序（至少基础三件）
- 商品详情（页面或弹层）：完整信息 + 行动按钮
- 匿名可浏览（看矩阵：匿名浏览、CU 可交互）

### 3. 逛→买动线接通（复用已有能力，契约零改动）
- 商品卡「发起采购意向」→ 客集 F3（POST /api/customer/intents）
- 「提交需求单」→ 客集 F2（POST /api/customer/demands）
- 供集 buyer 下单路径按现状能力接（GET /api/supply/orders buyer 特判已就绪）
- 未登录点交互 → 引导登录（不静默失败）

### 4. /goods（X-Goods=E-Market 通货集市）轻升级
- 若与 mall 共享商品数据模型：从占位页升级为真实商品列表（同源数据只读浏览 + 采购意向入口）
- 不做 B 端完整采购流程（那是后续工单）

## 红线
- 六套回归零破：embed-e2e 8/8 + embed-diag 12/12 + exchange 7/7 + api01 33/33 + gov01 38/38 + cont01（oneclick 48/48）
- crm-ui-check 27/27 + 截图基线（cont01 17/17 + struct01 7/7 + crm01 四图）

- 数据真实落库；禁外链不可达图

## 验收标准
- 新增 mall-check：商品数≥30、筛选/搜索/排序/详情断言、匿名浏览+CU 交互身份矩阵断言、意向/需求单动线断言
- 回报（一次）：commit hash + mall-check 结果 + 六套回归结果 + 截图清单（存 assets/mall01/）
